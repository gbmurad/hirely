Hirely’s static iPhone app website, prepared for GitHub Pages at https://gbmurad.github.io/hirely/. Publish the contents of this folder as the repository root; no build step or dependencies are required. The site includes the landing page (`index.html`), App Store support page (`support.html`), privacy policy (`privacy.html`), and terms of use with Apple’s standard EULA link (`terms.html`), with shared responsive CSS and local optimized artwork. Preview with `python3 -m http.server 8000` from this folder. All site navigation and assets use relative links; there are no scripts, remote fonts, analytics or trackers. Scroll-in effects use progressive CSS animation and respect reduced-motion settings. © 2026 George Murad.
